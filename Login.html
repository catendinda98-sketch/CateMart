# CateMart Online Shopping Website CateMart is an online shopping website built using HTML, CSS and JavaScript. ## Project Files - index.html - Home page - products.html - Products listing page - product-details.html - Product details page - login.html - Customer login page - register.html - Customer registration page - about.html - About page - contact.html - Contact page - cart.html - Shopping cart page - checkout.html - Checkout page - css/style.css - Website styling - js/script.js - Website functionality - images/ - Product images folder ## Technologies Used 1. HTML5 2. CSS3 3. JavaScript ## Features - Home page - Customer registration - Customer login demonstration - Product listings - Product categories - Product search - Product details - Shopping cart - Quantity management - Checkout page - Contact form ## How to Run 1. Open Visual Studio Code. 2. Open the CateMart folder. 3. Locate index.html. 4. Right-click index.html. 5. Select Open with Live Server. ## Important Information This is a front-end demonstration project. It does not include a secure backend, real customer accounts, a database, email delivery or actual M-Pesa payment processing.
